# نصب سرور «مدار ماه» روی orbit.mahsen81.ir (حدود ۵ دقیقه)

بازی به این آدرس وصل می‌شود: `https://orbit.mahsen81.ir/index.php`
دیتابیس SQLite است و رمز لازم ندارد؛ فایلش خودکار در `/home/mahsenir/orbit-data/` (بیرون از سایت) ساخته می‌شود.

## ۱. ساخت ساب‌دامنه
cPanel ← **Domains** ← **Create A New Domain**
- Domain: `orbit.mahsen81.ir`
- Document Root: `orbit.mahsen81.ir` (همان پیش‌فرض)
- Submit

## ۲. آپلود
cPanel ← **File Manager** ← پوشهٔ `orbit.mahsen81.ir`
1. **Upload** ← فایل `D:\job\bazi\orbit-drop-server\orbit-api.zip`
2. روی zip راست‌کلیک ← **Extract** ← Extract Files
3. فایل zip را پاک کنید.

## ۳. SSL
cPanel ← **Lets Encrypt™ SSL** (یا SSL/TLS Status) ← برای `orbit.mahsen81.ir` گواهی بگیرید.

## ۴. ساخت جدول‌ها
1. در مرورگر باز کنید: `https://orbit.mahsen81.ir/install.php` ← باید `OK: tables are ready` ببینید.
2. **`install.php` را از File Manager پاک کنید.**

## ۵. بررسی
`https://orbit.mahsen81.ir/index.php?a=board` ← باید `{"ok":true,"top":[]}` ببینید.
